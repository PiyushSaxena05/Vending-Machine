An end-to-end Vending Machine application built with:

🖥️ Java Swing GUI for an interactive and responsive desktop interface

🔧 JDBC for seamless database interaction (MySQL/SQLite)

💳 Realistic payment simulation with change handling and user feedback

🧰 Tech Stack
Layer	Tech Used
Frontend	Java Swing GUI
Backend	Java + JDBC + MySQL/SQLite
Styling	Java Swing Components & Layouts
Feedback	Swing Dialogs / Status Labels

📦 Features
Product selection with image & price display

Coin denomination input (₹1–₹500) and manual amount entry

Change calculation logic

Transaction logging via JDBC to local DB

Input validation and user feedback using dialogs and status messages

Reset and completion states with real-time UI updates
